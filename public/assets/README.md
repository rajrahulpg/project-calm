# Video assets

Drop the real files here with these exact names and the site picks them up automatically:

- `calm-artery.mp4` — the 31-second cinematic 3D coronary artery video
- `calm-artery-poster.jpg` — a still frame from the video, used as the `poster` before playback starts

Referenced from `src/data/content.ts` (`VIDEO_SRC`, `VIDEO_POSTER`, `VIDEO_DURATION`, `VIDEO_MARKERS`).
Until real files are added, the hero and scroll-video sections fall back to an abstract gradient automatically.
